# ClusterRide · datos de mapas

Programas que bajan datos abiertos oficiales de carreteras (carriles, límites de velocidad) y los preparan para el
servidor de rutas de ClusterRide. Se ejecutan solos en GitHub Actions cada dos meses y el resultado se publica como
fichero descargable en las versiones (Releases) de este repositorio.

Fuentes (todas con licencia abierta; se cita su origen):
- España: IGN · Información Geográfica de Referencia de Redes de Transporte (CC BY 4.0) y DGT · punto de acceso
  nacional (CC BY).
